# Etapa 5: Wireframes de baja fidelidad — CaféU

## Descripción de la etapa

Los wireframes de baja fidelidad definen la estructura y la ubicación de la información y los controles antes de aplicar el estilo visual final. Para este ejercicio se representan con marcos, líneas, textos y botones esquemáticos, sin fotografías ni colores de marca. Los wireflows pueden combinar una estructura de pantalla sencilla con el recorrido entre pantallas ([Nielsen Norman Group: Wireflows](https://www.nngroup.com/articles/wireflows/)).

## Wireframes propuestos

El archivo LaTeX contiene cinco pantallas esquemáticas: Menú, Revisión, Enviando pedido, Pedido recibido y Error de envío.

Fuente: [07_Wireframes_Baja_Fidelidad_CafeU.tex](07_Wireframes_Baja_Fidelidad_CafeU.tex).

Para generar el diagrama en PDF:

```bash
pdflatex 07_Wireframes_Baja_Fidelidad_CafeU.tex
```

## Estructura definida

- **Menú:** productos, precios, controles para agregar y acceso a la revisión.
- **Revisión:** productos seleccionados, cantidades, total, edición y confirmación.
- **Enviando:** respuesta visible mientras se procesa la acción.
- **Pedido recibido:** confirmación y resumen.
- **Error de envío:** explicación y acciones de recuperación.

Los wireframes muestran únicamente la estructura de las pantallas y las interacciones necesarias para completar el pedido.
